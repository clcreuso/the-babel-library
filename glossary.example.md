# Example English-to-French software glossary

- Source: English (`en`)
- Target: French (`fr`)
- object-oriented design / OOD: conception orientée objet / COO
- object-oriented programming / OOP: programmation orientée objet / POO
- responsibility: responsabilité
- dependency: dépendance
- coupling: couplage
- cohesion: cohésion
- inheritance: héritage
- composition: composition
- unit test: test unitaire
- refactoring: refactorisation

Preserve product names, programming language names, source code, commands, paths,
URLs, identifiers, class names, method names, variables, constants, modules,
libraries, and APIs. Use natural, professional French.
